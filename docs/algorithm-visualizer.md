# Phase 7: Algorithm Visualizer and Performance Dashboard

The visualizer plays bounded trace events generated by actual Dijkstra, A*, and Kruskal executions. It does not invent animation steps. Playback is client-side: play, pause, next, previous, reset, and speed controls replay already returned events without rerunning the backend.

Kruskal demonstrates a minimum spanning tree/forest for a bounded, connected subgraph of the loaded Pune dataset. It sorts undirected edge candidates by road-segment distance and uses disjoint-set union with path compression. It is not a route-finding algorithm.

The performance dashboard runs Dijkstra and A* repeatedly on identical graph nodes, edge costs, and traffic scenario. It reports actual measured execution averages plus visited nodes, explored edges, distance, and estimated time. Results should not be generalized beyond the selected inputs and runtime.
